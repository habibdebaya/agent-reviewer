What exactly are we preparing for fine-tuning?

A collection of input-and-answer pairs. The model's job will be to review an assistant's proposed email and return an approval decision.

Input given to the model

  • The rules for approving an email
  • What the task owner requested
  • The source notes and allowed recipient
  • The exact proposed email and earlier review history
→

Answer it should learn to produce

Approve or Reject, with the reason you selected and the note you wrote.

For the false Thursday launch claim, a useful answer is Reject · Unsupported information.

This page stores and exports the examples. Fine-tuning a language model is a later step outside this page. It does not happen when you review or download.

Download the training files

The download combines your completed decisions with the bundled samples. Each record contains the review instructions, model input, and expected answer.

  • train.jsonl contains {{ dataset.splits.get('train', 0) }} examples for teaching the model.
  • validation.jsonl contains {{ dataset.splits.get('validation', 0) }} separate examples for checking it during training.
  • manifest.json describes the package.

The {{ dataset.splits.get('test', 0) }} final test examples are left out so they can later check performance on examples the model was not taught. Downloading does not start a training job.
